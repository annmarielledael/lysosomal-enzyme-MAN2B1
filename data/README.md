# Data

This folder contains the human MAN2B1 protein sequence downloaded from the NCBI Protein database in FASTA format.

- `MAN2B1.fasta` — contains the protein sequence used for the amino acid composition and potential N-glycosylation motif analysis.

NCBI RefSeq accession: NP_000519.2

NCBI record: https://www.ncbi.nlm.nih.gov/protein/NP_000519.2
