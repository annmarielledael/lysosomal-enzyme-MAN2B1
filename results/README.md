# Results

This folder contains the output files generated by the R script for the MAN2B1 lysosomal enzyme analysis.

The files include:
- `MAN2B1_summary.csv` — summarizes the gene, protein accession, protein length, and number of potential N-glycosylation motifs.
- `MAN2B1_amino_acid_counts.csv` — contains the counts and percentages of each amino acid in the protein sequence.
- `MAN2B1_motif_positions.csv` — lists the positions and sequences of potential N-glycosylation motifs.
