# Figures

This folder contains the visualizations generated by the R script for the MAN2B1 lysosomal enzyme analysis.

- `MAN2B1_amino_acid_composition.png` — shows the amino acid composition of the MAN2B1 protein sequence.
- `MAN2B1_potential_N_glycosylation.png` — shows the potential N-glycosylation motifs identified in the protein sequence.

These figures summarize the results of the sequence analysis.
